# 3DQualMetrics

Combines Empir3D (Previously PQM) and QAL implementations into a single library

## File structure

- `Applications` - Contains the applications for the package
  - `Empir3D-Framework` - Contains the Empir3D point cloud assessment application
  - `QAL` - Contains the QAL loss function
  - `Quality-Metrics` - Contains the quality metrics including Empir3D (class), Chamfer distance, and Hausdorff distance
<!-- - `Samples` - Contains the sample data for the package -->
- `Utils` - Contains the utility functions and installations for the package
- `Config` - Contains the configuration files for the applications
